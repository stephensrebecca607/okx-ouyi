欧易 OKX 钱包浏览器插件

新电脑先安装受支持的浏览器，再从核实的产品页取得钱包插件。待扩展出现在本机菜单中后，按原钱包的恢复方式继续。

在电脑浏览器安装欧易 OKX 钱包插件

拿到新电脑准备恢复桌面端钱包时，先装好最新正式版的 Chrome 或 Microsoft Edge 浏览器，再经由官方钱包产品页跳转至对应的浏览器扩展商店。不要从旧电脑硬盘里直接拷贝浏览器扩展目录过去，那样既可能带入损坏的缓存，也会绕过商店的安全校验。

进入商店条目核对发布者认证与扩展编号无误后，点击添加到浏览器并同意所需的数据读写权限。安装完成后把图标固定到地址栏右侧，随后选择导入已有钱包，用离线保管的助记词或私钥在新电脑上完成恢复。

换电脑后怎样辨认原来的 OKX 钱包扩展？

浏览器账号同步功能有时会自动把旧电脑装过的扩展拉回新电脑，但同步并非百分百可靠，且绝不会把本地加密的私钥明文直接搬过来。为了防止在新电脑搜扩展时误装高仿山寨插件，最稳妥的办法是趁旧电脑还能用，先打开旧浏览器的扩展管理页，开启右上角开发者模式记下欧易钱包的专属扩展编号。

在新电脑的 Chrome 网上应用店或 Edge 加载项商店打开条目时，对照地址栏末尾那串扩展编号、发布者官方名称和用户规模。只要编号完全一致，就能百分之百确认装回的是同一个正版扩展。

更新 OKX 钱包插件前后应比较哪些字段？

浏览器扩展默认会在后台随商店自动静默更新，如果你想手动确认某次版本升级是否已经生效，打开浏览器扩展程序管理页，点进欧易钱包的详情卡片，重点比较更新前后的版本号、扩展编号和网站访问权限这三项字段。

升级完成后，版本号应当由旧变新，扩展编号保持原样不变，同时确认浏览器没有因为新版新增权限而把插件自动停用。如果升级后发现扩展图标从工具栏消失了，往往只是权限变更触发了暂停开关，进详情页复核权限并重新启用即可。

安装 OKX 钱包扩展时，如何确认重装扩展后的钱包显示？

在新电脑或重装扩展后导入原有助记词时，系统会要求你重新设定一个本机解锁密码，这个密码只管当前这台电脑的浏览器，与旧电脑密码不必完全一致。导入完毕进入主界面后，立即点开账户详情核对主要公链的收款地址首尾字符，确认它和旧电脑上记录的地址完全匹配。

如果原本在一个助记词下派生过多个子账户，记得点击添加账户依次把第二个、第三个派生地址重新调出来，否则首页默认只会先展示第一个主地址，容易让人误以为子账户里的资产不见了。

钱包浏览器插件遇到问题时的处理步骤

重装或升级插件后若出现解锁密码一直报错，先确认自己输入的究竟是这次新设的本机解锁密码，还是记成了旧电脑上的旧密码。只要手里握着完整的离线助记词，随时可以点击重置钱包并重新导入来设定新密码。

旧电脑准备淘汰或转交他人前，务必在确认新电脑扩展已经能正常查账并完成小额测试后，再于旧浏览器中彻底移除欧易钱包扩展并清空浏览器本地数据，避免残留加密文件带来隐患。
